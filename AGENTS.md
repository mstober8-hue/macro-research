# Macro-Research — Okun's Law in the AI Era

This project tests whether the historical link between GDP growth and
unemployment is weakening because of AI. See `README.md` for the full
methodology, findings, and verdict labels (Established / Reversed / Supports
/ Contradicts / Uncertain / Separate mechanism).

## Working with data gaps

Don't hesitate to ask Max for more data if it would sharpen an analysis —
a longer FRED pull, a different vintage, an additional series, access to a
paid data source. Ask for it rather than working around the gap.

And don't let a missing dataset stop a valid line of analysis. If the
reasoning is sound and a proxy, a partial series, or a documented assumption
can carry it forward, run with that and flag clearly what's provisional
(see the Established/Uncertain/Separate-mechanism labeling convention in
`README.md` — an "Uncertain" result that's honestly labeled is more useful
than no result at all). Missing data is a reason to flag and ask, not a
reason to drop the thread.
